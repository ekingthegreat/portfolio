Public Service Automation Project

The Problem Visitors seeking medical, financial, burial, and educational assistance suffered from confusing, unorganized manual lines, resulting in overcrowding, misplaced tickets, and long waiting times.
The Solution Built An automated web-based Queue Management System that issues categorized tokens, tracks waiting order, and displays real-time updates on a large screen with audio notifications.
Technologies Used PHP, MySQL, JavaScript, HTML5, CSS3, Local Network Server

Key Capabilities of the System

1. Kiosk Ticket Dispenser

Categorizes visitors according to requested service (e.g., Medical, Educational, Burial, Financial) and prints or generates unique sequential numbers.

2. Staff Counter Dashboard

Allows office tellers to call the "Next" constituent with one click, recall absent visitors.

3. Central Monitor Display

Large screen view placed in the waiting area displaying current numbers, counter assignments, and flashing notifications for newly called tickets.
