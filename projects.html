Leaflet.js OpenStreetMap PHP MySQL JavaScript
[ GIS MAP INTERFACE ]

Interactive spatial pins marking incident reports, flood zones, and evacuation shelters.

Live Geospatial System
The Problem During typhoons and flooding emergencies, disaster risk reduction officers struggle with inaccurate phone reports that lack precise coordinates, leading to slower rescue times and misallocated supplies.
The Solution Built A web-based geospatial disaster response platform that allows residents to report incidents with precise GPS coordinates, while providing emergency responders with a real-time command map.
My Specific Role Lead Developer on the thesis team: implemented the Leaflet.js map layer, built the MySQL geospatial database schema, wrote PHP API endpoints, and conducted usability tests with local officers.

Plotting active emergencies (Floods, Landslides, Medical) with visual color-coded map markers and status indicators.

Mobile-friendly form allowing citizens to attach photos, description, and automatically detect current GPS geolocation.

🛡️ Responders Command Center

Administrative portal to assign rescue units, mark incidents as resolved, and broadcast evacuation zone notifications.
